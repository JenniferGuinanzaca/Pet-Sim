# Nook

Nook is an interactive pet simulator built with react and vite. Inspired by my cat (sapporo) who wakes me up
every morning at 6 am.

This project lets users adopt a virtual cat or dog, give their pet a name, manage its stats, and keep it happy with actions like feeding, playing, and sleeping. Users can also buy items from the shop and use them through their inventory.

Stuff I wanted to add:
- A decay over time for the pets stats ( if you notice, happiness will no longer go down after you hit 100)
- Messages about the pet being like "(pet name) is happpy" or "(pet name) is bored" etc.
- Different Icons for the pet chosen so it's not just an emoji!
- A way where the user can earn money over time (so similar to stats decaying)

## Running Locally
1. clone this repository
2. open the terminal and run 'npm install'
3. run 'npm run dev'
4. open the local url shown
